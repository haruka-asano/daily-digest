# 夕刊(重大ニュースがあるときだけ)

1. `CLAUDE.md` と `SCHEMA.md` を読み、今日の朝刊(`data/YYYY-MM-DD.json`)を読む。
2. 朝以降のニュースを調べ、「重大ニュース」があるかを判断する。
   重大ニュースの基準(あとで持ち主と決める):
   - TODO: 例) AIの大きな発表、大きな災害、日銀・消費税など家計に直結する決定、映画祭や賞の発表。
3. 重大ニュースがなければ、**何も変更せず、何もコミットせずに終了する**。「夕刊なし」と報告するだけにする。
4. あれば `data/YYYY-MM-DD-evening.json` を書く(edition は "evening")。記事は1〜5本。
5. `node build.js --check` → `node build.js`。`data/` と `docs/` をコミットして、指示されたブランチにプッシュする。
   コミットメッセージ: `夕刊 YYYY-MM-DD`
