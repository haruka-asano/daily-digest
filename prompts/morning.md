# 朝刊を作る

1. `CLAUDE.md` と `SCHEMA.md` を読む。`data/` の最新の号も読み、重複を避ける。
2. 今日(日本時間)の日付で、次のジャンルを幅広く調べる: AI、デザイン、Web、経済・国際、トレンド、映画、お笑い、文化(美術展・音楽・本・舞台)。
   - AIは、OpenAI、Google、Anthropic、その他を同じ基準で。新機能、流出・うわさ(未確認と明記)、みんなの使い方も。
   - 映画は、ミニシアター、特集上映、映画祭、三大映画祭を中心に。
   - お笑いは、若手(結成20年以内)、賞レースの日程、配信、ライブ告知。
   - 美術展は、会期終了間近のもの、写真・絵画・インスタレーション、地方も。
3. `config.json` の `gallerySites` のサイトをすべて見て、今日の更新を `gallery` に入れる(ルールは `CLAUDE.md`)。そこから「今日の注目サイト」の記事(デザイン・Web)も作る。
3-2. Yahoo!リアルタイム検索で、AI・Web・デザイン・お笑いなどの話題を確認して `buzz` に入れる。
4. `data/YYYY-MM-DD.json` を書く(今日の日付、edition は "morning")。
   - 記事は全体で25〜35本。読むのに合計25〜30分ほど。
5. `node build.js --check` を通し、直してから `node build.js` を実行する。
6. `data/` と `docs/` をコミットして、指示されたブランチにプッシュする。
   コミットメッセージ: `朝刊 YYYY-MM-DD`
