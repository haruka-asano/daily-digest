解説形式検証は、プログラムが正しく動くことを、テストではなく数学の証明で示す方法。テストは「試した例では大丈夫」までしか言えないが、証明は「どんな入力でも大丈夫」と言い切れる。Leanは、その証明を機械が1行ずつ採点できる専用の言葉だ。これまでは専門家が何年もかける高価な作業で、ごく一部のソフトにしか使えなかった。つまり、身近なアプリの「安全です」に、数学の裏づけが付きやすくなる。
対象は、設計図だけでなく、スマホの上で実際に動くコードまで。専門家のチームなら数年かかる作業を、約4週間で終えたという。人の確認が必要だとAIが印を付けたのは、全体の約1%だった。
このしくみはSignalのほか、Googleメッセージなどでも使われる。毎日使うメッセージの暗号が、AIで点検される時代に入った。

解説推論(思考)は、AIが答える前に頭の中でメモを書くように考える段階。そのメモの量を「トークン」(文字のかけら)で数えると、考えた量の目安になる。今回は、そのメモの書き方と量が、ある日を境に変わったという指摘だ。ただ、画面のメモは要約なので、要約係が変わっただけの可能性も残る。つまり、同じ名前のAIでも「先週と同じ働き」とは限らないので、大事な作業は結果で確かめる。
最初の作業に移るまでの思考の量(中央値)は84から54に、約36%減った。コマンドの実行や編集の失敗を示す数は47%増えた。ある不具合直しは、設定「high」では160回やり取りしても直らず、約13ドルかかったという。
モデルの名前が同じでも、中身の動きは予告なく変わりうる。仕事で使うなら、同じ依頼の結果を時々見比べておくと気づきやすい。

Claude Codeの「今後は確認しない」で、パスワードが設定ファイルに残る。GitHubで1,122件

セキュリティ会社Apiiroは5日、Claude Codeの設定ファイルに、パスワードやAPIの鍵が平文で残り、GitHubに公開されている例を報告した。調べた約10万4,000件のうち、1,122件(約1.1%)に秘密の情報があった。

解説APIの鍵は、サービスを使うための「合いかぎ」。GitHubに公開したフォルダーに合いかぎを置くと、誰でも拾って使える。「今後は確認しない」は毎回の確認を省く便利なボタンだが、許したコマンドを丸ごとメモに書き残す。前との違いは、AIの便利機能そのものが、漏れの通り道になった点だ。つまり、AIに許可を出すときは、パスワードを直接書いたコマンドにだけは「今後は確認しない」を使わない。
原因は、コマンドの実行を「はい、今後は確認しない」で許すしくみ。許したコマンドが、まるごと「.claude/settings.local.json」に保存される。コマンドにパスワードが入っていれば、それも一緒に残る。
Claude Codeを使ったフォルダーを公開しているなら、このファイルを確認する。パスワードが入っていたら、ファイルを消すだけでなく、パスワードそのものを変える。
もっと詳しく

古い版や会話の記録まで含めると、1,994のリポジトリで2,539の秘密が見つかったという。Apiiroは鍵が使えるかは試していないが、1社は有効な鍵だったと認めた。Anthropicの説明書では、このファイルは開発者のパソコン側で公開から外す設定が入る。ただ、その設定はプロジェクトについて回らず、すでに記録済みのファイルには効かない。2025年8月に同じ問題の報告が出ていたが、動きがないまま自動で閉じられていた。
