経済 / 米国
重要度 ★★★1分

Metaに250億ドルの制裁金。ケンブリッジ・アナリティカ問題で、米州裁判所

米ニューメキシコ州の司法省は10月21日(現地)、同州がFacebookを訴えた裁判で、裁判所がMetaに250億ドル(約3兆9500億円)の民事制裁金を命じたと発表した。州は、企業への金銭的制裁として米国史上最大級だとしている。

解説制裁金は、法律を破った会社に科す罰のお金。裁判では、「個人情報の扱いを、利用者に誤解させた」と判断された。1件ずつ数えて最大5000ドルを科せるので、件数が4000万件を超えると巨額になる。つまり、サイトの説明と実際の個人情報の使い方がずれると、大きな金額の責任になりうる。
9月25日に陪審が、個人情報の扱いなどについて消費者に誤解を招く説明をしたとして、州の法律に違反する行為を4389万9725件と認定していた。1件につき最大5000ドルの制裁金を科せる法律で、額は裁判官が決めた。
個人情報の説明の仕方(プライバシーポリシーの書き方)が、大きな金額の責任につながることがある。サイトの文言は、実際の動きと合わせておく。
もっと詳しく

事件は2018年に発覚した、英国のデータ分析会社による、Facebook利用者の情報の不正利用。Metaが今後、控訴するかどうかは、私の検索では確認できていない。

EVなどの購入補助金、2027年1月から6〜8割に。経産省が見直し

経済産業省は10月21日、電気自動車(EV)などの購入を補助する「CEV補助金」を見直すと発表した。補助額は、いまの6〜8割ほどに抑える。2027年1月1日以降に新車として登録する車に、見直し後の額を適用する。

解説補助金は、国が買う人に出す手助けのお金。それが減ると、買う人の実質の支払いが増える。新車として登録する日で決まるので、2026年内に登録するか、2027年に入るかで差が出る。つまり、EVを買うつもりの人は、年末までに買うほうが得になる場合がある。
補助金に頼っていた買い手には、実質の負担が増える。年末までに買う動きが出やすい。
車のサイトやキャンペーンページを作る側は、「補助金の額」「適用の日付」を、更新しやすい形で作っておく。
もっと詳しく

Web / 緊急
重要度 ★★★2分

PHPの重大な欠陥の修正版が出た。制作者・サイト管理者が、今日やること

何が起きたか: Webで広く使われる言語「PHP」に、外から命令を実行されかねない「緊急」の欠陥が2件見つかった。修正版は日本時間21日午後11時ごろに公開された(8.5.12、8.4.27、8.3.36、8.2.35)。公開前に情報が出回り、攻撃の試みも見られたと報じられている。BASE、pixiv、ニコニコ、さくらのレンタルサーバなどが、緊急メンテナンスや停止をした。

どこまで影響するか: PHP-FPM、mod_php、php-cgi、FrankenPHP、LiteSpeedが対象。とくにmod_phpは危険とされる。更新の対象外の8.1以前は、ベンダーに確認するか、サポート中の版へ移るよう呼びかけられている(7.4・8.0・8.1向けには、最小限の修正を入れたソースが公開された)。WordPressなどを更新しても、PHP本体を直さないと直らない、という解説も出ている。
いまやること: (1) 自分のサーバーのPHPの版を確認し、修正版か、事業者の更新パッケージに上げる。(2) レンタルサーバーは、会社のお知らせを見る。直せないときは、サイトを一時的に止める手もある、と政府も呼びかけた。(3) 公開前の対策としてあげられた設定(アップロード状況のセッション記録を切る)は、単体では完全ではない。(4) 更新後に、怪しい動きがないか、ログを見る。
もっと詳しく

欠陥の番号は CVE-2026-109618 / CVE-2026-109619。WordPress、Laravel、Symfonyなどさまざまな構成で再現するという研究者の報告がある。OpenAIはバージョン確認ツールを出した。自分で直せない場合は、制作会社・保守会社に、いつ直すかを必ず聞く。
