Anthropicが株式の5％を公益目的の新組織へ。企業価値が50％上がるごとに2％を追加

Anthropicは10月18日(米国時間)、自社株の一部を新組織「Anthropic Public Benefit Fund」に拠出すると発表した。株主の承認を前提に、まず5％。企業価値が基準から50％上がるごとに、取締役会の判断で2％を足す。

新組織は非営利団体ではなく、完全子会社のLLC。持つ株式は、ロビー活動や政治献金には使わない。創業者らが保有株の80％を寄付すると誓約していることと合わせて、株式の約20％が公益目的になるという。一方で、新組織の仕組みや追加の基準額は「今後数カ月以内に公表」とされ、まだ具体的には決まっていない。6月にはIPO(株式公開)に向けた書類を米当局に出したと発表済みで、今回の発表はIPOには触れていない。
AI企業が「お金の使い道」をどう決めるかは、使うツールを選ぶ理由の一つになる。ただし、仕組みが固まるまでは、約束の段階として見ておくのがよい。

米国が中国DeepSeekの製品を、連邦の民間機関から排除する命令

Studio不正アクセスの続報。影響は企業・自治体のサイトに広がり、件数の公表を待つ段階

何が起きたか: 制作ツール「Studio」のクラウド環境に、9月30日〜10月1日に第三者が不正アクセスし、登録顧客の情報が外に出た可能性がある。10月13日に検知し、13〜14日に弱点を直した。

どこまで影響するか: フォームの送信内容、CMSやデザインのデータ、外部サービスのAPIキー(連携用の“鍵”)などが対象になりうる。一部の暗号化データは、復号用の鍵も読み出されたという。Link-Uグループは問い合わせ7,663件、埼玉県は162件で、漏えいの可能性を発表した。全体の件数は調査中で、続報で出る予定。不正利用は確認されていないとされる。
いまやること: Studioのパスワードを変える。Studioに登録したAPIキーやトークンは、発行元で作り直す。公開プレビューのURLも再発行する。フォームで個人情報を集めていたら、お客さまへの案内と、詐欺メールへの注意喚起も考える。

名画をあしらった限定デザイン。クロスの「星のある風景」を映した8色アイシャドウパレットが11,000円、クリムトの肖像画を描いた3色ブラッシュ(限定2色)が7,480円、モネの「ひまわりの花束」の限定デザインのリップバーム(全16色)が各5,060円。ほかに、リップグロス3本セットが各6,050円、ブラシ3本セットが19,800円。
アートが好きな人への贈り物にもなる。値段の幅が広いので、リップやグロスなら5,000〜6,000円台から選べる。
