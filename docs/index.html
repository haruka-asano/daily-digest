解説「ベンチマーク」は、AIの力を比べるための共通の試験だ。これまでの試験の多くは「この税額を計算して」と問いを渡していたが、実際の相談では、依頼人自身が問題に気づいていないことが多い。つまり、AIは「聞かれたこと」には強くなったが、「聞かれていないが大事なこと」を自分で見つける力はまだ弱く、専門家の確認を外せる段階ではない。
各モデルに50課題を5回ずつ解かせ、採点項目の95%以上を満たせば合格とした。1位はAnthropicのClaude Sonnet 5.5で、250回中27回(10.8%)。2位はClaude Fable 5.1の9.6%、3位はClaude Opus 5.5の9.2%だった。

解説ここでの「台帳」は、商品の名前、値段、仕様、評判などを1か所にまとめた巨大なデータの集まりだ。AIの買い物係はこの台帳を読んで「どれが良いか」を答えるので、台帳を持つ会社は、売り場の棚の並べ方を決める店長に近い立場になる。つまり、AIで買い物をする人が増えるほど、商品が見つけてもらえるかどうかが、Amazonの台帳に載るかどうかに左右されやすくなる。
