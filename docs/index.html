重要度 ★★★2分

日銀、1.25%で据え置き。「物価2%に到達」と初めて判断

日銀は30日、政策金利を1.25%程度に据え置いた。同時に、物価の基調が2%の目標と「おおむね整合的」と判断した。2013年に目標を決めてから、初めてのこと。8人が賛成し、高田委員は1.5%への利上げを求めて反対した。

解説「基調的な物価上昇率」は、天候や原油の一時的な値動きを除いた、物価のもとの流れ。これが2%前後で安定すれば、日銀は「お金をたくさん流して物価を押し上げる」役目を終え、「物価を安定させる」役目に移れる。つまり、日銀の仕事は「アクセル」から「速さの調整」に変わり、今後は金利が少しずつ上がる方向だと考えておくとよい。
9月は、2%に届くのを2026年度後半から2027年度としていた。それより早い判断になった。据え置きの理由は、9月の利上げが経済や物価に与える影響を見たいから。今後も利上げで緩和の度合いを調整する方針は変えていない。
預金やローンの金利は、まだ動かない。ただ、日銀は「利上げの道は続く」と言っている。変動金利で借りている人は、次の利上げを頭に置いておきたい。
もっと詳しく

同じ会合で、日銀が持つ上場投資信託(ETF)の売却ペースを、年約8600億円に速めると決めた。政府は、物価が上がり続けているが、デフレ脱却宣言はまだ出していない。今回の物価上昇は、エネルギー価格などの外からの要因が大きく、賃上げが続くかが課題とされる。
