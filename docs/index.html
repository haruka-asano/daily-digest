Anthropic、Claudeで「攻撃される入口」を減らす研究を公開。OpenSSHの修正にも貢献

Anthropicが20日(米国時間)、ソフトウェアの「外から届く範囲」を洗い出して縮める研究の初期結果を出した。オープンソース25件(500万行超)を調べ、493件の問題を見つけた。

1件ずつ欠陥を直すのでなく、使わない機能を初期設定で切る、認証の後ろへ移す、といった形で入口そのものを狭める考え方。未発見の欠陥が残っても、悪用されにくくなる。
サイトやサーバーを預かる人にとっては、「更新を急ぐ」に加えて「使わない機能を切る」も守りになる、という見方の材料になる。
もっと詳しく

認証を前提とする11件すべてで、意図せず外から届くコードが見つかった。162件の設定の組み合わせが、警告なしで受け入れられていた。OpenSSH 10.4では、認証前に届く約4500行の実験的コードが見つかり、10.5と10.6で対策された(10.6は10月6日公開)。Anthropicは、この手法を脆弱性発見サービス「OSS Scanner」に組み込む予定としている。数字はITmedia NEWSの要約による。

出典: ITmedia NEWS

PHPの欠陥、公表の4日前から悪用の試み。Amazonが観測

何が起きたか: 米Amazonが、PHPの緊急の欠陥2件(通称「PHP2Shell」)を狙う試みを、10月17日に観測していたと明かした。公表は21日なので4日前になる。

どこまで影響するか: 修正版の公開は日本時間21日23時。悪用コードは21日午前11時ごろから出回り、修正後も数時間で新しいものが出たという。公表前に情報をどう得たかは、わかっていない。
いまやること: 修正版にしたあと、ログの調査は「公表日」でなく、少なくとも10月17日までさかのぼって見る。時間単位で対応する、という前提に切り替える。
もっと詳しく

AmazonのCISOは、AIで修正内容から攻撃コードを作りやすくなり、攻撃までの時間が数時間、場合によっては数分に縮まっていると指摘した。見直すべき点として、(1)深刻な欠陥への対応を時間単位で管理する、(2)調査は最初の悪用時点から始める、(3)攻撃の型に頼らない検知に投資する、の3つを挙げた。

映画 / アニメ
重要度 ★★☆1分

「リロ&スクラッチ」の日本版声優が発表。スティッチは山寺宏一さん

ディズニーの短編アニメ「リロ&スクラッチ」の日本版声優が決まった。リロは永尾柚乃さん、スティッチは山寺宏一さん、ジャンバ博士はシソンヌの長谷川忍さん。

12月4日公開の「ビリーと魔法のはじまり」と同時上映。「リロ&スティッチ」以来、23年ぶりの劇場公開の完全新作アニメ。
長く続く作品の声を、同じ人が受け継ぐ形。キャラクターの見せ方の連続性として見ておく。
もっと詳しく

あらすじは、リロがいない間、スティッチが新しい家族の猫型キャラクター、スクラッチの世話を任される話。

出典: 映画.com

映画 / 邦画
重要度 ★★☆1分

藤原季節さん主演「赤土に眠る」。考古学者・相澤忠洋の若き日。2027年3月公開

映画「赤土に眠る」は、日本に旧石器時代があったことを示した考古学者・相澤忠洋の若い頃を描く。監督は金子雅和さん、上映時間は116分。2027年3月公開予定。

相澤は1946年、群馬の旧笠懸村岩宿(現みどり市)で石器を見つけた。みどり市の市制20周年の記念事業として作られる。
身近な土地の歴史を、映画にする例。地方発の企画の作り方として面白い。
もっと詳しく

藤原さんは役作りで、東京と群馬を自転車で往復した(約200km)。特別内覧会は、相澤ゆかりの笠懸野文化ホールで開かれた。

出典: 映画.com

プーマ×ジル サンダーの第3弾。初のアパレル。10月23日から

トラックジャケットは8万円、トラックパンツは7万5000円、長袖トップスは3万5000円。靴はスピードキャットとスウェードで、各7万7000円。

ファッション / 展示
重要度 ★★☆1分

ラルフ ローレン創業60周年の「ポロフェス」。原宿で10月23〜25日、入場無料

ラルフ ローレンが、創業60周年を記念した世界初の大規模展「ポロフェス」を開く。日本が第1弾で、会場はヨドバシJ6ビル(渋谷区神宮前)。23日から25日までの3日間。

ニューヨークに置くアーカイブを、ウエスタン、スポーツ、カレッジなどの型で見せる。日本の刺し子の繕い文化に目を向けた、3組との再生品の展示もある。
入場無料だが事前予約制。トークも各回予約が要る。服の「古さ」を、新しい価値として見せる展示の例。
もっと詳しく

隣では国内外17店の古着店が、約1万点を売る。期間中は、松任谷正隆さん、長谷川昭雄さん、森星さんらのトークがある。

出典: FASHIONSNAP
